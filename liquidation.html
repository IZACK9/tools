Liquidation distance indicator

Set your leverage. It draws the estimated price where the position would be liquidated, and how far away that is right now.

How to use (free, 1 minute)

  1. Copy the code below.
  2. Open any chart on TradingView (a free account works).
  3. Open Pine Editor at the bottom, delete what's there, paste, and click Add to chart.
  4. Click the indicator's ⚙️ to set side, leverage, and entry price.
//@version=5
// Liquidation Distance — Candle That Kills
// Draws an estimated liquidation price for a leveraged position and shows how far away it is.
// Educational tool only. Not financial advice. Estimates use isolated margin and ignore fees and funding.
indicator("Liquidation Distance — Candle That Kills", shorttitle="Liq Distance", overlay=true)

side      = input.string("Long", "Position side", options=["Long", "Short"])
lev       = input.float(10.0, "Leverage (x)", minval=1.0, maxval=200.0, step=1.0)
useClose  = input.bool(true, "Use current price as entry")
entryIn   = input.float(0.0, "Entry price (if not using current price)", minval=0.0)
mmrPct    = input.float(0.5, "Maintenance margin rate (%)", minval=0.0, maxval=10.0, step=0.1)
warnPct   = input.float(2.0, "Warn when liquidation is closer than (%)", minval=0.1, step=0.1)

entry = useClose or entryIn <= 0 ? close : entryIn
mmr   = mmrPct / 100.0
isLong = side == "Long"

// Isolated-margin estimate: position is closed when loss reaches (1/leverage - maintenance margin)
liq = isLong ? entry * (1.0 - 1.0 / lev + mmr) : entry * (1.0 + 1.0 / lev - mmr)
distPct = math.abs(close - liq) / close * 100.0
danger = distPct < warnPct

liqColor = danger ? color.new(color.red, 0) : color.new(color.orange, 0)
plot(liq, "Liquidation price", color=liqColor, linewidth=2, style=plot.style_stepline)
plot(useClose ? na : entry, "Entry price", color=color.new(color.gray, 30), linewidth=1, style=plot.style_linebr)

var table t = table.new(position.top_right, 2, 4, bgcolor=color.new(color.black, 20), border_width=1)
if barstate.islast
    table.cell(t, 0, 0, "Leverage", text_color=color.silver)
    table.cell(t, 1, 0, str.tostring(lev, "#.#") + "x " + side, text_color=color.white)
    table.cell(t, 0, 1, "Liquidation", text_color=color.silver)
    table.cell(t, 1, 1, str.tostring(liq, format.mintick), text_color=liqColor)
    table.cell(t, 0, 2, "Distance", text_color=color.silver)
    table.cell(t, 1, 2, str.tostring(distPct, "#.##") + "%", text_color=danger ? color.red : color.white)
    table.cell(t, 0, 3, "Status", text_color=color.silver)
    table.cell(t, 1, 3, danger ? "< " + str.tostring(warnPct, "#.#") + "% away" : "OK", text_color=danger ? color.red : color.teal)

alertcondition(danger, "Liquidation getting close", "Price is within your warning distance of the estimated liquidation price.")
What it assumes

Isolated margin. Liquidation ≈ entry × (1 − 1/leverage + maintenance margin) for longs, and × (1 + 1/leverage − maintenance margin) for shorts. Real exchanges also count fees, funding, and their own maintenance tiers, so your actual liquidation can be a bit closer. Treat the line as an estimate, not a promise.
